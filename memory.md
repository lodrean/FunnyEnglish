# memory.md — долгосрочная память проекта FunnyEnglish

> Читается AI-агентом перед началом работы. Дополняется после важных
> архитектурных решений и найденных граблей (раздел «Решения и договорённости»).

## 1. Архитектура проекта

Кроссплатформенное приложение для изучения английского с геймификацией. Монорепо:

- `backend/` — Spring Boot 3.4.1 (Kotlin 2.1.0, Java 21), PostgreSQL + Flyway, JWT (jjwt 0.12.6), S3/MinIO для медиа. Порт 8080.
- `admin-web/` — React 18 + TypeScript + MUI 6 + TanStack Query 5 + react-router-dom 6, Vite 5. Порт 3000.
- `composeApp/` — ОСНОВНОЙ KMP-модуль UI (android/ios/desktop/wasmJs). Монолит: весь рабочий код в `app/screens/*`, `app/viewmodel/*`, `app/di/*`.
- `app/` — тонкая Android-обёртка (`FunnyEnglishApplication` + `MainActivity`).
- `shared/` — KMP: `api/FunnyEnglishApi.kt` (Ktor-клиент), модели, `GuestProgressRepository`.
- `core/`, `core:domain`, `core:data`, `core:presentation` — инфраструктура (DI, HttpClientFactory, Result/UiText, общие UI-компоненты).
- `feature-api` + `feature-*` — целевая модульная архитектура (Clean Architecture по фичам). **ВАЖНО: в composeApp не подключены; `:feature-tests` пустой.** Новый код писать в composeApp, если нет явной задачи на миграцию (ADR-006).
- `design/` — дизайн-система KMP (Material 3).
- Навигация: ручная БЕЗ NavHost — `sealed class AppScreen` + `mutableStateOf` в `composeApp/.../app/App.kt`. (В feature-api задуман navigation-compose 2.8 + `FeatureNavigator`, не используется.)

## 2. Конвенции кода

- **DI — Koin 4.0.0.** Паттерн: `val xxxModule = module { single { ... }; viewModel { ... } }` (пример: `composeApp/.../app/di/AppModule.kt`). Старт НЕ через `startKoin`, а `KoinApplication { modules(appModule) }` в `App.kt`; VM через `koinViewModel()`. Платформенный конфиг — expect/actual `provideAppConfig()`.
- **Presentation — MVI на StateFlow.** Тройка файлов на экран: `XxxState.kt` (data class), `XxxAction.kt` (sealed), `XxxEvent.kt`; ViewModel: `MutableStateFlow(State())` + `Channel<Event>.receiveAsFlow()` + `fun onAction(...)` с when. Пример: `feature-home/.../presentation/HomeViewModel.kt`. Ошибки — `UiText?`.
- **Data — Ktor 3.0.2 + safeCall + Result.** Repository: `override suspend fun getX(): Result<X, DataError.Network> = safeCall { api.getX() }` (пример: `feature-home/.../data/HomeRepositoryImpl.kt`). Json: `ignoreUnknownKeys=true, isLenient=true`. Токен — `PersistentTokenProvider` (multiplatform-settings, ключ `auth_token`). Картинки — Coil 3.
- **Типы-обёртки**: рабочие `Result`/`DataError` лежат в `core/domain/util/` — импортировать оттуда (в `core/domain/` есть устаревшие дубли!).
- **Комментарии и коммиты** — по существу; документация на русском в `docs/`.
- Admin-web: страницы в `src/pages/`, API в `src/api/client.ts` (axios, токен в localStorage), E2E в `e2e/` (Playwright, Page Object в `e2e/pages/`).

## 3. Команды сборки и проверки

```bash
# Mobile
./gradlew :app:assembleDebug        # Android APK
./gradlew :composeApp:run           # Desktop
./gradlew :composeApp:desktopTest   # тесты KMP (kotest 5.8, commonTest)
./gradlew :composeApp:uiTest        # UI-тесты (кастомная задача, **/tests/**)
# ./gradlew lint — НЕ настроен: detekt-плагин объявлен (apply false), но ни один модуль его не подключает!

# Backend (требует PostgreSQL на 5432)
./gradlew :backend:bootRun

# Admin
cd admin-web && npm run dev         # vite, порт 3000
cd admin-web && npm test            # vitest
cd admin-web && npm run test:e2e    # playwright

# Всё вместе
docker compose up -d                # postgres:5432, minio:9000/9001, backend:8080, admin:3000

# E2E
cd e2e-cmp && npx playwright test   # E2E десктопного CMP-приложения
maestro test .maestro/              # мобильные флоу
```

Base URL API: Android — gradle-property `FUNNYENGLISH_API_BASE_URL` (дефолт `http://10.0.2.2:8080/`); Desktop — env `FUNNYENGLISH_API_BASE_URL` (дефолт `http://localhost:8080`).

## 4. Известные грабли

1. **ModernAudioPlayer отключён** (`ModernAudioPlayer.kt.disabled`, KMP-компиляция). Вместо него: jlayer (desktop) + Media3 ExoPlayer (android).
2. **BUG-004**: URL медиа `http://minio:9000/...` — внутренний Docker hostname, недоступен с устройств (`docs/issues/BUG-004-minio-internal-url.md`).
3. **JSONB workaround**: `backend/.../service/TestService.kt:267` — «Delete questions first (workaround for JSONB deserialization issue)».
4. **Napier недоступен на WASM** — закомментирован в commonMain composeApp, стаб в wasmJsMain; kotest глобально исключён из-за WASM (`wasmJsTest` srcDirs обнулены).
5. **Feature-флаги** `ENABLE_DRAG_DROP_QUESTIONS`, `ENABLE_IMAGE_WORD_MATCH`, `ENABLE_DEBUG_TOOLS`: ON в debug / OFF в release (composeApp/build.gradle.kts); на desktop — env `FUNNYENGLISH_ENABLE_*`.
6. **Дубли `Result`/`DataError`** в `core/domain/` vs `core/domain/util/` — легко импортировать не тот (см. конвенции).
7. **BUG-001/002/003** (закрыты): не отображался текст вопроса; любой ответ «правильный»; кнопка «Завершить тест» не работала (`docs/issues/`).
8. **Исторические баги**: detekt не подключён ни к одному модулю — `./gradlew lint` не является quality gate.
9. **Context-path backend = `/api`** (`application.yml`): все health-check'и, прокси и API-коллекции должны учитывать префикс. Actuator health: `http://localhost:8080/api/actuator/health` (на корне `/actuator/health` — 404).
10. **Newman-коллекция** (`api-tests/`): baseUrl должен быть `http://localhost:8080/api` (без `/api` — массовые 404). Известные расхождения: invalid login отдаёт 400 (коллекция ждёт 401), без авторизации Spring отдаёт 403 (коллекция ждёт 401).
11. **Playwright admin-web**: конфиг по умолчанию поднимает vite на 5173 (`webServer`). Против docker-админки запускать: `SKIP_WEB_SERVER=1 ADMIN_URL=http://localhost:3000 npx playwright test`.
12. **minio-init.sh внутри mc-контейнера**: MinIO недоступен как localhost — только `http://minio:9000` (доменное имя сервиса compose).
13. **Proxyman/Charles на хосте ломает эмулятор**: глобальный http_proxy 10.0.2.2:9090 подставляется автоматически → все запросы на 10.0.2.2:8080 дают `504 Proxy Error` (Proxyman не может смаршрутизировать emulator-алиас). Обход: собрать APK с LAN-IP хоста: `./gradlew :app:assembleDebug -PFUNNYENGLISH_API_BASE_URL=http://192.168.x.x:8080/` (proxyman тогда форвардит нормально).
14. **Maestro text matching — ТОЧНЫЙ по умолчанию**: `assertVisible: "Привет!"` НЕ матчит «Привет! 👋». Использовать regex: `".*Привет!.*"`. Тексты флоу (.maestro/flows) синхронизированы с UI после UX Modernization (2026-07-20): «Рейтинг» (не Лидерборд), «Ваш результат», «Завершить тест», «5 / 5 правильно».
15. **Raw Ktor exceptions в UI**: при ошибке сети пользователь видел дамп `NoTransformationFoundException` с URL и FAQ-ссылкой. ИСПРАВЛЕНО (2026-07-20): `ErrorMessage` в `components/Common.kt` маппит технические сообщения в человеческие (`userFriendlyError`). Долгосрочно — маппинг в UiText на уровне ViewModel.
16. **UserFlow UI-тесты (commonTest) были заглушками**: `*ScreenForTest` рендерили пустой `MaterialTheme {}` (реальный экран закомментирован) — 51/76 падали. 2026-07-21 переписаны на РЕАЛЬНЫЕ экраны + моковые state (TestMocks.kt) + captured callbacks → 74/74. Теги добавлены в реальные экраны (home_screen, question_text, submit_button, results_view и др.). Compose-тесты: ноды часто в unmerged-дереве (`useUnmergedTree = true`); клики внизу экрана — через `performScrollTo()` (бросает AssertionError — ловить Throwable); ввод в FunnyTextField — `hasAnyAncestor(hasTestTag(tag)) and hasSetTextAction()`.
17. **ImageWordMatchQuestion баги (из тестов)**: (а) hotspot'ы не рендерились без загруженной картинки (originalImageSize=0) → fallback на размер контейнера; (б) NaN-прогресс при 0 словах (деление на 0 → краш LinearProgressIndicator) → guard; (в) тег `iwm_word_bank` перенесён на Column (пустой FlowRow схлопывается в 0x0 → not displayed).
18. **backend обязан иметь `jackson-module-kotlin`** (добавлен 2026-07-21, был только parameter-names из spring-boot-starter-json). Без него: `is`-префиксные Boolean в request-DTO молча НЕ биндятся (`CreateAnswerRequest.isCorrect` → все ответы `is_correct=false` → любой сабмит теста = 0 баллов!); отсутствующие поля с Kotlin-дефолтами → NPE → 500 вместо дефолта; сериализация отдаёт `correct`/`published` вместо `isCorrect`/`isPublished`. Симптом в ответах API: если видишь `"published":...` вместо `"isPublished"` — модуль не подхвачен.
19. **nginx admin: proxy_pass с литеральным hostname резолвит DNS один раз при старте** — после пересоздания backend-контейнера прокси отдаёт 502 до рестарта admin (директива `resolver` при этом НЕ помогает: она работает только при proxy_pass через переменную). Фикс (2026-07-21): `set $backend_upstream http://backend:8080; proxy_pass $backend_upstream;` — рантайм-резолв через Docker DNS; маппинг identity (/api/ → /api/). Проверено: прокси переживает `docker compose up -d --force-recreate backend` без рестарта admin.
20. **`POST /api/questions` content — JsonNode, не sealed interface** (2026-07-21): `QuestionContentRequest` без дискриминатора не десериализуется (500); DEDUCTION невозможен (TEXT_SELECT и IMAGE_SELECT имеют одинаковые поля). Решение: `content: JsonNode?` в DTO + типизированный маппинг в `QuestionService.mapContentToLegacy` по `type` в legacy-поля (text/audioUrl) и Answer-строки (скоринг `TestValidationService` работает ТОЛЬКО по legacy answers — JSONB content в entity закомментирован). Без этого фикса вопросы из нового TestEditor сохранялись БЕЗ ответов (тест неиграбелен) или падали с 500.
21. **Spring Data projection + native query**: нельзя проецировать `java.sql.Timestamp` в `OffsetDateTime` (500 на `/admin/analytics/recent-activity`). В projection-интерфейсе — `java.sql.Timestamp` (грабля поймана E2E 2026-07-21).
22. **Admin Playwright — типовые грабли спеков** (починено в krx, 2026-07-21): (а) ручной логин в beforeEach ломается при storageState (редирект с /login на / → timeout на input[type=email]) — auth только через setup-проект; (б) `networkidle` нестабилен (TanStack Query) — ждать `[data-testid="page-title"]`; (в) клик по MUI Select option на mobile перехватывается Backdrop — выбирать клавиатурой (ArrowDown+Enter); (г) MUI Switch input скрыт — click({force:true}); (д) пункты меню — ListItemButton (div[role=button]), не <a>/<button>; (е) mobile drawer — Modal-портал, признак открытия — видимый [data-testid^="nav-"] в .MuiModal-root (НЕ backdrop/nav:visible); (ж) step-name в IWM-редакторе скрыт CSS на mobile — шаги переключать focus+Enter (div.step tabindex=0); (з) проекты chromium*/Mobile/tablet должны testIgnore /tests\/navigation\// (иначе navigation-спеки гоняются с storageState и падают).
23. **Rate limiting логина (5/мин/IP) ломает E2E-сьюты** — десятки логинов → 429 → флаки login-спеков. Лимиты через env `RATE_LIMIT_LOGIN_CAPACITY`/`RATE_LIMIT_REGISTER_CAPACITY` (дефолты безопасные 5/3; в dev-compose выставлены 100/50). В prod env НЕ выставлять (2026-07-21).
24. **Мобильный drawer админки был icon-only**: Sidebar renderNavItem замыкался на desktop `open` → на mobile (open=false) пункты меню без подписей. Фикс: renderNavigationContent(expanded)/renderLogoSection(expanded), mobile drawer — всегда expanded=true (2026-07-21).
25. **`POST /api/admin/tests` с deprecated `CreateQuestionRequest`**: ответ `questions: []` — это маппинг ответа, вопросы РЕАЛЬНО создаются (проверять через `GET /api/questions/test/{id}/details` или БД). Типы вопросов — enum `QuestionType` (TEXT_SELECT и др.), НЕ MULTIPLE_CHOICE (400).
26. **Admin E2E флаки под параллельной нагрузкой**: при одновременном запуске admin Playwright-сьюта и e2e-cmp (WASM-компиляция ест CPU) 3-5 тестов падают с `page.goto: Timeout 15000ms` (navigation.spec, iwm/complete-test-suite). Без параллельной нагрузки те же тесты зелёные (проверено ре-раном 22/22, 2026-07-27). Сьюты запускать последовательно.
27. **admin-web `npm run lint` локально падает с 12 errors**, если собран `storybook-static/` — eslint линтит сгенерированный бандл (нет ignore), правила `regexp/*`, `jsx-a11y/*` не найдены в его контексте. В CI каталога нет → gate зелёный. Локально удалить `storybook-static/` перед lint или добавить ignore.
28. **Proxyman VPN-приложение на эмуляторе** (`com.proxyman.proxymanvpn`): держит активный tun0 и роутит трафик ПРИЛОЖЕНИЙ (не shell) на мёртвый прокси хоста — приложение/Chrome не ходят в сеть, при этом `nc`/`ping` из adb shell работают (shell вне VPN). Диагностика: `ip addr show tun0`, лечение: `adb shell am force-stop com.proxyman.proxymanvpn`. Дополнительно `settings put global http_proxy :0` (настройка переживает рестарт AVD!). Признак: иконка ключа в статус-баре + «Упс! Нет соединения» в приложении. (2026-07-27)
29. **Эмулятор с `-no-snapshot-save` теряет установленные APK при рестарте** — после `emu kill` приложение нужно ставить заново. И http_proxy сбрасывается обратно на 10.0.2.2:9090 (лежит в snapshot AVD).
30. **Bash-пайпы маскируют exit code**: `maestro test ... | tail -5` всегда 0 → ложные «PASSED» (так же `npm run lint | tail`). Статус проверять ТОЛЬКО по реальному exit code: `cmd > file 2>&1; CODE=$?`. (2026-07-27, поймано на Maestro: «6/6» было на самом деле 1/6)
31. **Hibernate validate: Kotlin `Int` ↔ `INTEGER`, не `SMALLINT`** — DDL со SMALLINT падает на старте («wrong column type: found int2, expecting integer»). Спека Part 1 → v1.1 (grades: SMALLINT → INTEGER). (2026-07-31)
32. **Generated column `grades.total` в тестах**: H2 (test profile, `ddl-auto: create-drop`) не строит generated column из аннотаций → в `Grade.total` добавлен `columnDefinition` с H2-синтаксисом `GENERATED ALWAYS AS (...)` (в prod не используется — там Flyway DDL). После save нужен `entityManager.refresh(grade)`, чтобы подтянуть вычисленное значение; при этом save новой сущности grade = persist (тот же инстанс managed), а `saveAndFlush(submission)` = merge → `refresh` на исходном инстансе падает «Entity not managed». (2026-07-31)
33. **Mockito-inline + Kotlin non-null params → NPE при stubbing** (`any()` возвращает null, срабатывает intrinsic check). `@MockitoBean` для final Kotlin-класса `StorageService` не подходит. Решение: `@TestConfiguration` + `@Primary` бин через mockk (`SpeakingFlowIntegrationTest.StorageServiceMockConfig`). (2026-07-31)
34. **Newman резолвит file-вложения от cwd, не от файла коллекции**: `src: "api-tests/fixtures/practice.m4a"` работает при запуске из корня репо и падает «file load error» из `api-tests/`. (2026-07-31)
35. **Ktor Auth bearer кэширует результат loadTokens** (в т.ч. null): при логине в середине сессии (гость → логин) запросы уходили БЕЗ Authorization → 403; после перезапуска приложения (токен в Settings сразу) — работало. Поймано Maestro practice_auth 2026-07-31. Фикс: Auth-plugin убран из `shared/api/FunnyEnglishApi.kt`, токен добавляется в `defaultRequest { header(Authorization) }` на КАЖДЫЙ запрос. Побочка: авто-refresh по 401 убран — истёкший токен = повторный логин.
36. **«Залипший экран» после логина/регистрации** (вторая итерация грабли onboarding→guest): в App.kt ветка `is AppScreen.Login/Register` не реагировала на смену `authState.mode` — после успешного логина пользователь оставался на экране логина. Легаси-баг (не покрывался флоу: гость всегда шёл через онбординг). Фикс: `LaunchedEffect(authState.mode)` + сравнение с `initialMode` (remember) — переход в Library только при СМЕНЕ mode, иначе гость, открывший логин для конверсии, отскакивал бы обратно. (2026-07-31)
37. **Maestro 2.7: нет команды `sleep`** («Invalid Command»). Фиксированные ожидания — через `extendedWaitUntil` по тексту таймера (`visible: "1:17"`). Placeholder в FunnyTextField НЕ тапается — тапать по label («Email», «Пароль»); следующее поле перекрыто клавиатурой — `hideKeyboard` перед тапом. Тексты матчатся ТОЧНО с учётом регистра — regex `.*учителю автоматически.*`. (2026-07-31)
38. **String.format недоступен в KMP/WASM** — `compileKotlinWasmJs` падает «Unresolved reference 'format'». Округление вручную (`kotlin.math.round(x*10)/10`). Проверять `compileKotlinWasmJs`, не только desktop/android. (2026-07-31)
39. **Docker-образ backend устаревает молча**: `docker compose up -d` поднял СТАРЫЙ образ без speaking-эндпоинтов (500 NoResourceFound вместо 404/200). Перед живыми прогонами — `./gradlew :backend:bootJar && docker compose build backend && docker compose up -d backend`. (2026-07-31)
