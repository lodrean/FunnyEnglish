## 🏠 Вариант 1: Домашний Сервер (500₽/мес)

### Что нужно
- Старый ПК/ноутбук (4 ядра, 8GB RAM, SSD)
- Стабильный интернет (upload 20+ Mbps)
- Электричество ~100W

### Архитектура
```
┌────────────────────────────────────────────────┐
│  Домашний ПК                                   │
│  ├─ Ubuntu Server                              │
│  ├─ Docker (PostgreSQL + Backend + Admin)      │
│  └─ Nginx (reverse proxy)                      │
└──────────────────┬─────────────────────────────┘
                   │
           Cloudflare Tunnel
                   │
    https://admin.sotospeak.ru
```

### Быстрый старт (30 минут)

```bash
# 1. Установить Ubuntu Server на ПК
# Скачать: https://ubuntu.com/download/server

# 2. Запустить установочный скрипт
curl -fsSL https://sotospeak.ru/install.sh | bash

# 3. Установить Cloudflare Tunnel
wget -q https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
sudo dpkg -i cloudflared-linux-amd64.deb
cloudflared tunnel login
cloudflared tunnel create sotospeak

# 4. Настроить DNS в Cloudflare
# A-записи: api.sotospeak.ru, admin.sotospeak.ru

# 5. Запустить
cd /opt/sotospeak && docker-compose up -d
```

### Плюсы
✅ Самый дешёвый  
✅ Полный контроль  
✅ Нет ограничений трафика  
✅ Можно апгрейдить железо  

### Минусы
❌ Зависит от домашнего интернета  
❌ Нужен ИБП (бесперебойник)  
❌ Нет гарантии uptime  
❌ Сложнее масштабировать  

**Итог:** Отлично для тестирования и MVP (до 100 пользователей)

## 🚀 Быстрый Старт (Выбор + Деплой)

### Шаг 1: Выбрать вариант (2 минуты)
```
Есть старый ПК и хочется поэкспериментировать? → Домашний сервер
Хочу стабильность за разумные деньги? → Timeweb VPS
Хочу максимально сэкономить? → Hybrid
```

### Шаг 2: Зарегистрироваться (5 минут)
```
Домашний: Ничего не нужно, берём старый ПК
Timeweb: https://timeweb.cloud → Регистрация
Hybrid: Timeweb + Yandex Cloud (Object Storage)
```

### Шаг 3: Деплой (15-30 минут)
```bash
# Все варианты используют один скрипт:
curl -fsSL https://sotospeak.ru/install.sh | bash

# Или вручную:
git clone https://github.com/your/sotospeak.git
cd sotospeak/docker
./deploy.sh --target=timeweb  # или --target=home
```

### Шаг 4: Настроить домен (5 минут)
```
1. Купить .ru домен (reg.ru, nic.ru)
2. A-запись api → IP сервера
3. A-запись admin → IP сервера
4. Ждать 5-15 минут (DNS propagation)
```

### Шаг 5: SSL сертификат (автоматически)
```bash
# Let's Encrypt выдаётся автоматически
# Или вручную:
docker-compose run --rm certbot certonly --standalone -d api.sotospeak.ru -d admin.sotospeak.ru
```

## ❓ FAQ

**Q: Можно ли начать с домашнего сервера и потом переехать?**  
A: Да! Бэкап БД, перенос на VPS, restore. Процесс занимает ~30 минут.

**Q: Что если домашний интернет упадёт?**  
A: Пользователи увидят ошибку. Для критичных сервисов лучше VPS.

**Q: Нужен ли статический IP?**  
A: Нет! Cloudflare Tunnel работает с динамическим IP.

**Q: Сколько пользователей выдержит VPS за 600₽?**  
A: ~1000 одновременных. При росте апгрейд до 4GB RAM.

**Q: Можно ли использовать один VPS для нескольких проектов?**  
A: Можно, но не рекомендуется для production.
