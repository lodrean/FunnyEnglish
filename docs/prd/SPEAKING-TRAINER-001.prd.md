## Overview
Полный пивот продукта: So to Speak превращается из тестово-игрового приложения в **тренажёр устной речи**. Ученик выбирает тему (Library) → топик (Topic) → смотрит видео (с субтитрами или без) → отвечает на вопросы голосом в одном из двух режимов: **Training** (локальная тренировка с эскалацией таймера, записи не покидают устройство) или **Practice** (30 секунд на все ответы, запись уходит на сервер учителю). Учитель в admin-web прослушивает записи и оценивает по рубрике критериев.

## Goals
1. Дать ученику структурированную практику speaking: видео-контекст → вопросы → устные ответы.
2. Training-режим: безопасная среда для многократных попыток с прогрессивным ограничением времени (80с → 50с → 30с).
3. Practice-режим: контрольная точка — короткая запись, отправляемая учителю.
4. Дать учителю удобный inbox для прослушивания и оценивания записей.
5. Переиспользовать существующую инфраструктуру (Spring Boot backend, MinIO, admin-web, KMP-каркас) без переписывания с нуля.

## User Stories

### Story 1: Библиотека тем
As a ученик, I want видеть список тем (Library) и топиков внутри темы, so that выбирать интересный материал для практики.

**Acceptance Criteria:**
- [ ] Экран Library показывает список опубликованных тем (название, обложка, количество топиков)
- [ ] При выборе темы открывается список топиков (название, длительность видео, статус прохождения)
- [ ] Пустые темы (без топиков) скрыты от ученика
- [ ] Список доступен гостю без регистрации
- [ ] Pull-to-refresh и индикатор загрузки; ошибка сети — дружелюбное сообщение (userFriendlyError)

### Story 2: Просмотр видео
As a ученик, I want смотреть видео топика с субтитрами или без, so that понимать контекст перед ответами.

**Acceptance Criteria:**
- [ ] При входе в топик предлагается выбор: «С субтитрами» / «Без субтитров»
- [ ] Видео проигрывается встроенным плеером (play/pause, seek, fullscreen-опционально)
- [ ] Субтитры отображаются синхронно поверх видео (формат WebVTT)
- [ ] Переключатель субтитров доступен и во время просмотра
- [ ] Повторный просмотр возможен неограниченно
- [ ] Кнопка «Перейти к вопросам» доступна всегда (просмотр всего видео не обязателен)

### Story 3: Вопросы к топику
As a ученик, I want видеть список вопросов к видео, so that готовить ответы.

**Acceptance Criteria:**
- [ ] После/вместо видео открывается список вопросов (текст на английском)
- [ ] Виден выбор режима: Training / Practice
- [ ] Practice-режим для гостя заблокирован с CTA «Войти/Зарегистрироваться»

### Story 4: Training-режим
As a ученик, I want тренировать устные ответы с записью голоса и уменьшающимся лимитом времени, so that довести ответ до автоматизма.

**Acceptance Criteria:**
- [ ] Вопросы видны без ограничения времени (этап подготовки)
- [ ] Ровно **3 попытки** на топик; каждая попытка — **одна запись с ответами на ВСЕ вопросы подряд**; попытка N использует лимит уровня N: попытка 1 → 80 сек, попытка 2 → 50 сек, попытка 3 → 30 сек (level-chip «Уровень N · X сек» + индикаторы шагов)
- [ ] На экране записи виден **весь список вопросов** топика (как в Practice) — ученик отвечает на все сразу в одном голосовом сообщении
- [ ] Таймер виден во время записи; по истечении — автостоп; досрочный ручной стоп засчитывает попытку
- [ ] Записанную попытку можно только **прослушать** (play/pause + прогресс); удалять и перезаписывать попытки нельзя; ✅ «принята» проставляется автоматически
- [ ] Записи хранятся **только локально** на устройстве; на сервер ничего не отправляется
- [ ] Записи привязаны к топику (номеру попытки) и переживают перезапуск приложения
- [ ] После 3-й попытки — финальный блок: «Перейти к практике» / «Вернуться в библиотеку» / «Начать заново с попытки 1»
- [ ] Из любого места Training можно вернуться в Library

### Story 5: Practice-режим
As a ученик, I want записать ответы на все вопросы за 30 секунд одной записью и отправить учителю, so that получить оценку.

**Acceptance Criteria:**
- [ ] Доступен только авторизованным пользователям
- [ ] После нажатия «Начать» запускается запись и таймер 30 секунд; ученик отвечает на все вопросы подряд одной записью
- [ ] По истечении 30 секунд — автостоп; досрочный ручной стоп также завершает запись
- [ ] **Без review**: запись автоматически уходит учителю сразу после остановки; прослушать/перезаписать/изменить нельзя (на экране — предупреждение об этом)
- [ ] Запись загружается на сервер (multipart, аудио в MinIO) и появляется у учителя со статусом NEW
- [ ] Ученик видит статус отправки (NEW → REVIEWED) и, после проверки, оценку с комментарием
- [ ] Повторная отправка при незавершённой (NEW) записи блокируется (409 `DUPLICATE_SUBMISSION`); клиент при 409 удаляет временный файл и показывает состояние «уже отправлено»
- [ ] После REVIEWED повторная отправка разрешена (петля роста; bd h3l.2)
- [ ] При ошибке сети — retry; запись не теряется

### Story 6: Администрирование контента
As a учитель/админ, I want управлять темами, топиками, видео и вопросами, so that наполнять тренажёр контентом.

**Acceptance Criteria:**
- [ ] CRUD тем (Library): название, описание, обложка, порядок, публикация
- [ ] CRUD топиков: привязка к теме, название, загрузка видео (MinIO), загрузка субтитров (WebVTT), порядок, публикация
- [ ] CRUD вопросов к топику: текст, порядок
- [ ] Неопубликованный контент не виден ученикам

### Story 7: Проверка записей (Grading)
As a учитель, I want прослушивать practice-записи учеников и оценивать по рубрике, so that давать обратную связь.

**Acceptance Criteria:**
- [ ] Inbox записей: список с фильтром по статусу (NEW/REVIEWED), ученику, топику, дате
- [ ] Прослушивание записи встроенным плеером + видны вопросы топика
- [ ] Оценка по рубрике: grammar / vocabulary / pronunciation / fluency (1–10 каждый) + общий балл (авто-усреднение) + текстовый комментарий
- [ ] После сохранения статус → REVIEWED; оценка видна ученику
- [ ] Оценку можно отредактировать (аудит: updated_at)

## Edge Cases
| Case | Handling |
|------|----------|
| Нет разрешения на микрофон | Запрос runtime permission; при отказе — объяснение + ссылка в настройки; запись недоступна |
| Прерывание записи (звонок, сворачивание) | Автостоп; в Training попытка засчитывается, в Practice — автоматическая отправка как при ручном стопе |
| Нет микрофона / занят другим приложением | Ошибка с понятным текстом, не crash |
| Обрыв сети при upload practice-записи | Файл хранится локально до успешной отправки; retry вручную/автоматически |
| Видео не загружается | Дружелюбная ошибка + retry; к вопросам можно перейти без видео |
| Субтитры отсутствуют у топика | Режим «с субтитрами» недоступен (выбор скрыт) |
| Поворот экрана во время записи/просмотра | Состояние записи и таймера переживает конфигурацию (ViewModel) |
| Мало места на устройстве | Ошибка при старте записи с пояснением |
| Ученик отправляет practice дважды, пока запись NEW | Отклонено: 409 `DUPLICATE_SUBMISSION` (bd 7vm); в inbox одна запись |
| Ученик отправляет practice после REVIEWED | Разрешено (bd h3l.2, 2026-09-06): создаётся новая запись, оценённая остаётся в истории |
| Учитель открыл inbox, пока записей нет | Empty state с пояснением |
| Удаление топика/вопроса, к которому есть записи | Записи сохраняются; топик помечается архивным (soft delete) |

## Technical Constraints
- **KMP-монолит `composeApp`** (ADR-006): новые экраны — там; MVI (State/Action/Event + Channel), Koin, Ktor + safeCall, UiText для строк.
- **Android-first**: `VoiceRecorder` и видео-плеер — expect/actual; iOS/Desktop/WASM — стабы «недоступно на этой платформе».
- Видео: Media3 ExoPlayer (уже в проекте для аудио); субтитры — WebVTT, парсинг на клиенте или отдача cues с backend (решить в спеке).
- Аудио-формат записи: AAC/m4a (Android MediaRecorder), лимит ~1–2 МБ на practice-запись.
- Backend: context-path `/api`; новые миграции Flyway (V17+); jackson-module-kotlin учитывать (грабля №18 memory.md).
- Загрузка файлов: nginx `client_max_body_size 50m` — для видео может потребоваться увеличение.
- Auth: JWT (существующий); practice-эндпоинты — только ROLE_USER+; grading — ROLE_ADMIN.
- MinIO URL для клиентов — публичный (`S3_PUBLIC_URL`, BUG-004).

## UI/UX
- **Новые экраны**: LibraryScreen, TopicsScreen, VideoScreen, QuestionsScreen, TrainingScreen (recorder + таймер + список записей), PracticeScreen (таймер 30с + отправка), MySubmissionsScreen (статусы/оценки).
- **Admin**: разделы «Speaking Content» (Libraries/Topics/Questions) и «Grading» (inbox + плеер + рубрика).
- **Navigation flow**: Library → Topics → Video (выбор субтитров) → Questions → Training|Practice → (Practice) MySubmissions. Из Training — назад в Library.
- **Дизайн**: дизайн-система **Playful Coach v1.1 (вариант B)** (`.docs/design-system/`: tokens.json, мокапы эталонных экранов, icons.svg); токены → `:design` + MUI-тема. Требования мокапов по флоу Training/Practice авторитетны.
- **Loading/Error states**: скелетоны списков; userFriendlyError для сетевых ошибок; disabled-состояния кнопок записи без permission.

## Dependencies
- Backend: новые сущности/контроллеры (libraries, topics, videos, speaking_questions, practice_submissions, grades) + Flyway V17+.
- Admin-web: 2 новых раздела; переиспользование MediaUploader.
- shared: новые методы в `SoToSpeakApi` (публичный контент, multipart upload, мои submissions).
- Новые зависимости: парсер WebVTT (или свой), возможно `okio` для файлов в KMP.

## Metrics
- Количество practice-отправок на ученика/неделю
- Доля записей, получивших REVIEWED за 48 часов
- Использование Training: среднее число записей на вопрос, доля достигших уровня 30с
- Конверсия гость → регистрация (гейтинг Practice)
- Ошибки записи/upload (crash-free > 99%)

## Out of Scope
- Автоматическая оценка речи (ASR/AI-scoring) — будущая фича
- iOS/Desktop/WASM-реализации записи и видео
- Удаление legacy-фич (тесты, словарь, геймификация) из кодовой базы
- Пуш-уведомления о выставленной оценке
