## Быстрые правки

- Тексты экранов: в HTML прототипа ищи секции `scr-*`.
- Цвета: блок `:root` в начале файла (тёмная тема — класс `.dark`).
- Навигация: атрибуты `data-go` / `data-back` / `data-tab` (значение = id экрана без префикса).
- После правок навигации прогони валидатор: `node .openclaw/tmp/validate.js prototype "<файл>"`.
- Источник дизайн-токенов продукта: репозиторий `.docs/design-system/tokens.json`.

## Правило версий

Любая правка HTML: сначала скопировать активную версию в `archive/`, затем писать новую как `V2`.
Снапшоты не редактируются. Откат — копированием из `archive/` (команды в §3.3).
