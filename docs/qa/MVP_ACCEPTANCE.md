> Дата: 2026-08-01. Основание: `docs/prd/SPEAKING-TRAINER-001.prd.md`, план `docs/plan/SPEAKING-TRAINER-001.md` (gate Фазы 5 — go/no-go владельца).

## 1. Ученик (Android-приложение)

| # | Сценарий | Ожидаемый результат | ✓ |
|---|----------|--------------------|---|
| 1.1 | Первый запуск | Splash → онбординг (3 слайда: «Смотри видео» → «Тренируйся вслух» → «Отправь учителю») → «Начать» → **Library** (гость, без регистрации) | ☐ |
| 1.2 | Library | Список библиотек с обложками-инициалами, чипы «НОВАЯ», прогресс-бары; bottom nav «Темы/Отправки/Профиль» | ☐ |
| 1.3 | Тема → Топик | Тап «Разговорный английский» → список топиков → тап «Знакомство» → **сразу видео** (без bottom-sheet) | ☐ |
| 1.4 | Видео | Плеер с кастомными контролами (big-play, seek, время, CC), чипы «С субтитрами/Без субтитров», субтитры под плеером; CTA «Перейти к вопросам» доступен всегда | ☐ |
| 1.5 | Questions | Список вопросов; у гостя — SpeakingGate «Ты почти у цели!» с «Зарегистрироваться»/«Войти»; «Тренировка · 3 попытки» доступна | ☐ |
| 1.6 | Training, попытка 1 | Таймер-кольцо 80 сек, запись одним голосовым на все вопросы, досрочный стоп засчитывается, ✅ автоматически | ☐ |
| 1.7 | Training, попытки 2–3 | Лимиты 50/30 сек; «Попытки · N из 3»; записи только прослушивание (удаления нет); после 3-й — финальные CTA | ☐ |
| 1.8 | Записи Training локальны | Записи НЕ уходят на сервер (нет POST /api/speaking/submissions в логах backend) | ☐ |
| 1.9 | Practice-гейт гостя | Тап «Зарегистрироваться» в гейте → Register; «Войти» → Login | ☐ |
| 1.10 | Регистрация | «Создай аккаунт»: имя/email/пароль → аккаунт создан | ☐ |
| 1.11 | **Подтверждение email** (после реализации add-email-verification) | Письмо в Mailpit → ссылка → «Почта подтверждена»; Practice доступен только после подтверждения | ☐ |
| 1.12 | Practice | «Практика · 30 сек» → таймер-кольцо 30 сек → запись → ручной стоп «Закончить и отправить» или автостоп → **автоотправка без Review** | ☐ |
| 1.13 | Sent | «Запись отправлена!», чип «статус NEW · ждёт проверки», «Вернуться в библиотеку» | ☐ |
| 1.14 | Retry при ошибке сети | Отключить сеть → отправка падает с человеческим сообщением → после восстановления сети запись отправляется (retry) | ☐ |
| 1.15 | MySubmissions («Отправки») | Запись со статусом «На проверке»; после grading (п. 2.4) — «Проверено» + баллы по критериям и комментарий | ☐ |
| 1.16 | Профиль | Аватар с инициалами, статистика (отправки/топики), «Выйти» (danger-ghost) | ☐ |
| 1.17 | Повторный запуск | Сессия сохраняется: Splash → сразу Library (без онбординга и логина) | ☐ |

## 3. Нефункциональные проверки

| # | Проверка | Критерий | ✓ |
|---|----------|----------|---|
| 3.1 | Нет HTTP 5xx | Логи backend за прогон: без 500 (в т.ч. guest-events, submissions, analytics) | ☐ |
| 3.2 | Нет сырых технических текстов | Ошибки сети/сервера показываются человеческими сообщениями (без stacktrace/URL/exception-дампов) | ☐ |
| 3.3 | Дизайн-конформити | Экраны соответствуют мокапам Playful Coach v1.1 (реестр `docs/qa/design-conformance/REPORT.md` закрыт) | ☐ |
| 3.4 | WCAG | Чипы статусов читаемы (контраст AA), record ≠ error по цвету | ☐ |
| 3.5 | Email-доставка | Письмо верификации в Mailpit содержит рабочую ссылку; resend rate-limited | ☐ |
