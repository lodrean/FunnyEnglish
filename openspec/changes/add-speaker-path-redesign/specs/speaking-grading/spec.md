# speaking-grading Specification (delta)

## ADDED Requirements

### Requirement: Клиентский бейдж оценок
Клиент (composeApp) SHALL показывать на вкладке «Отправки» бейдж с числом practice-сабмишнов,
перешедших в REVIEWED после локальной метки `submissions_last_seen`. Метка хранится локально
(multiplatform-settings) и обновляется при открытии вкладки «Отправки»; серверных изменений
(эндпоинтов, полей) изменение не требует — счётчик вычисляется из существующего списка
сабмишнов клиента по `reviewedAt`.

#### Scenario: Ученик узнаёт об оценке без захода в отправки
- **WHEN** после последнего визита в «Отправки» появилась новая оценка
- **THEN** на вкладке навигации отображается бейдж с числом новых оценок до следующего визита
