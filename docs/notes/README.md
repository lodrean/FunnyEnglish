# Session Notes

Эта папка содержит заметки по задачам и проектам.

## Структура
- `<ticket-name>.md` - заметки по конкретному тикету
- `architecture-decisions.md` - архитектурные решения
- `lessons-learned.md` - извлечённые уроки

## Формат заметки

```markdown
# <Название задачи>

## Контекст
Что делали и зачем

## Решения
Какие решения приняли и почему

## Проблемы
С чем столкнулись

## Уроки
Что узнали
```

## Использование
После каждого PR обновляй соответствующую заметку.
Ссылайся на заметки в контексте: "см. docs/notes/<task>.md"
