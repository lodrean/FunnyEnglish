# /prove - Доказательство работоспособности

Докажи что текущие изменения работают корректно.

## Шаги
1. **Определи scope изменений** - какие файлы изменены
2. **Сравни поведение** main vs текущая ветка
3. **Запусти релевантные тесты**
4. **Покажи diff в поведении** - что изменилось

## Методы доказательства
- Юнит тесты: покажи что они проходят
- API тесты: покажи примеры запросов/ответов
- UI: опиши что пользователь увидит
- Логи: покажи что логируется

## Результат
Предоставь убедительное доказательство что фича работает как ожидается.
