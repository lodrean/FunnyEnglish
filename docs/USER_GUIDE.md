# FunnyEnglish — Инструкция по работе с приложением

> Версия 1.0 · 2026-07-21
> Документ для двух аудиторий: **ученик** (мобильное/десктоп/web-приложение)
> и **учитель** (админ-панель).

---

## Часть 1. Ученик

### 1.1. Первый запуск и онбординг

При первом запуске приложение показывает короткий онбординг из 3 экранов:

1. **Приветствие** — чем занимается приложение (короткие тесты с картинками и аудио).
2. **Геймификация** — звёзды, уровни (XP), достижения и рейтинг.
3. **Выбор режима** — как вы хотите пользоваться приложением:
   - **«Зарегистрироваться»** — полный режим (см. 1.2).
   - **«Продолжить как гость»** — без регистрации (см. 1.3).
   - «У меня уже есть аккаунт» — вход для существующих пользователей.

Онбординг показывается один раз. Выбор запоминается на устройстве.

### 1.2. Полный режим (зарегистрированный пользователь)

Регистрация: email + пароль + имя. После регистрации доступно всё:

| Раздел | Что там |
|---|---|
| **Главная** | Продолжить обучение, виджеты streak и XP, рекомендации |
| **Категории** | Темы (Животные, Цвета, Числа…), внутри — тесты |
| **Тест** | Вопросы разных типов: выбор ответа, картинки, аудио, drag-and-drop, «слово к области на картинке» |
| **Результат** | Баллы, звёзды (0–3), XP, ачивки за прохождение |
| **Профиль** | Уровень, XP, серия дней (streak), статистика, история |
| **Достижения** | Ачивки и ежедневные квесты |
| **Рейтинг** | Лидерборд среди всех учеников |
| **Сообщения** | Сообщения и комментарии от учителя (иконка в профиле, бейдж непрочитанных) |

**Советы:**
- Заходите каждый день — серия (streak) даёт бонусы.
- 100% правильных ответов = 3 звезды и ачивка «Отличник».
- Учитель может прислать сообщение или комментарий к тесту — проверяйте входящие (бейдж на профиле).

### 1.3. Гостевой режим (без регистрации)

Можно играть сразу, без email и пароля:

- ✅ Проходить тесты во всех категориях.
- ✅ Прогресс сохраняется **локально на устройстве**.
- ✅ Адаптивные уроки.
- ⛔ Статистика, достижения, рейтинг и история — **только после регистрации** (экраны показывают предложение зарегистрироваться).
- ⛔ Прогресс не синхронизируется между устройствами.

**Про обезличенные данные.** В гостевом режиме приложение отправляет в общую
статистику только анонимные события: факт запуска сессии и факт прохождения
теста (баллы/время), привязанные к случайному идентификатору устройства.
**Имя, email и любые личные данные не собираются и не передаются.**
Связать анонимный идентификатор с конкретным человеком невозможно.

### 1.4. Переход из гостя в аккаунт

Зарегистрируйтесь или войдите из профиля («Войти или зарегистрироваться») —
приложение предложит **перенести гостевой прогресс** в аккаунт (диалог после
входа). После переноса локальный прогресс станет облачным, откроются
статистика, ачивки и рейтинг.

## Часть 2. Учитель (админ-панель)

Админка: `http://localhost:3000` (в проде — ваш домен). Вход: учётная запись администратора.

### 2.1. Контент

**Категории** (`Content → Categories`) — темы тестов: название, описание, иконка, порядок.

**Тесты** (`Content → Tests`):
1. «Add Test» → вкладка **General**: название, категория, сложность, статус (Draft/Published), обложка.
2. Вкладка **Questions** — вопросы по кнопкам типов:
   - **Multiple Choice** — варианты ответа, переключатель «Correct» у правильного.
   - **Fill in Blank** — пропуск в тексте.
   - **Matching** — пары для сопоставления (drag-and-drop).
   - **🖼️ Image Word Match** — картинка + слова: загрузите изображение, добавьте 2–8 слов, обведите области (hotspots) и привяжите слова.
3. **Save** — тест и все вопросы сохраняются. Опубликованный (`Published`) тест сразу виден ученикам.

> ⚠️ Вопрос без отмеченного правильного ответа считается непроходимым —
> всегда проверяйте переключатели «Correct».

### 2.2. Ученики

`Users` — список учеников: уровень, очки, streak, пройденные тесты.
Карточка ученика — детали прогресса. Кнопка **сообщения** — отправить:

- **MESSAGE** — простое сообщение ученику.
- **COMMENT** — комментарий с привязкой к конкретному тесту (например, «попробуй ещё раз»).

Ученик видит сообщения в приложении (входящие в профиле) с бейджем непрочитанных.

### 2.3. Аналитика

`Analytics` — метрики платформы: пользователи, прохождения, средний балл, графики активности.

Секция **«Guest Users (anonymous)»** — обезличенная статистика гостей:

- **Total Guests** — сколько уникальных устройств запускали приложение в гостевом режиме.
- **Active (7d)** — активные гости за последние 7 дней.
- **Tests Completed** — сколько тестов пройдено гостями.
- **Conversion** — доля гостей, зарегистрировавшихся впоследствии.

Данные полностью анонимны: ни имени, ни email, ни IP — только случайный ID устройства.

### 2.4. Настройки

`Settings` — параметры платформы (уведомления, лимиты, режимы).

## Часть 3. Частые вопросы (FAQ)

**Ученик удалил приложение в гостевом режиме — прогресс пропал?**
Да: гостевой прогресс хранится локально. Чтобы не терять — зарегистрируйтесь.

**Можно ли играть на двух устройствах?**
С аккаунтом — да (прогресс в облаке). Гостем — нет.

**Что видит учитель о госте?**
Только обезличенные счётчики (см. 2.3). Персональных данных гостя у учителя нет.

**Как отменить публикацию теста?**
Откройте тест в админке → статус Draft → Save.
