# speaking-practice Specification

## Purpose
Приём голосовых practice-записей ученика и выдача ему истории своих отправок с оценками учителя. Детали реализации — `docs/SPEAKING_TRAINER_SPEC_PART1.md` v1.0.
## Requirements
### Requirement: Отправка practice-записи
Система SHALL принимать от авторизованного пользователя голосовую запись (multipart/form-data: файл + topicId + durationSec) для опубликованного неархивного топика. Файл MUST быть аудио из whitelist (m4a/aac/mp3/wav/ogg), размером не более 5 МБ; durationSec MUST быть в диапазоне 1..60. Файл SHALL сохраняться в S3-хранилище по ключу, содержащему идентификатор пользователя и UUID, а запись SHALL создаваться со статусом NEW. Повторные отправки на один и тот же топик SHALL быть разрешены.

#### Scenario: Успешная отправка
- **WHEN** авторизованный ученик отправляет валидную запись 30 секунд на опубликованный топик
- **THEN** создаётся submission со статусом NEW (201), audioUrl — публичный URL хранилища

#### Scenario: Гость не может отправить запись
- **WHEN** неавторизованный пользователь пытается отправить practice-запись
- **THEN** возвращается 401/403, запись не создаётся

#### Scenario: Отправка на неопубликованный топик
- **WHEN** ученик отправляет запись на топик, который не опубликован или архивирован
- **THEN** возвращается 404 «Topic not found», запись не создаётся

#### Scenario: Невалидные параметры
- **WHEN** ученик отправляет файл больше 5 МБ, или durationSec вне 1..60, или файл недопустимого типа
- **THEN** возвращается 400 с описанием ошибки, запись не создаётся

### Requirement: История отправок ученика
Система SHALL предоставлять авторизованному пользователю список его собственных practice-записей, отсортированный от новых к старым, с текущим статусом и, для оценённых, с оценкой по рубрике (4 критерия, усреднённый балл, комментарий, имя проверившего, даты создания и редактирования оценки).

#### Scenario: Ученик видит свою оценку
- **WHEN** ученик запрашивает свои отправки после того, как учитель оценил одну из них
- **THEN** оценённая запись имеет статус REVIEWED и содержит оценку с усреднённым баллом; неоценённые — статус NEW и `grade: null`

#### Scenario: Чужие записи недоступны
- **WHEN** ученик запрашивает свои отправки
- **THEN** возвращаются только его собственные записи, записи других учеников не включаются
