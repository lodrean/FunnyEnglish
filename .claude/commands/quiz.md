# /quiz - Проверка понимания кода

Погоняй меня по изменениям в коде. НЕ делай PR пока я не пройду тест.

## Правила
1. Задавай вопросы по логике изменений
2. Проверяй понимание edge cases
3. Спрашивай про возможные баги
4. Тестируй знание архитектурных решений

## Формат
- Задавай по одному вопросу
- Жди мой ответ
- Давай фидбек: правильно/неправильно + объяснение
- Веди счёт: X/Y правильных

## Критерий прохождения
Минимум 80% правильных ответов для одобрения PR.
