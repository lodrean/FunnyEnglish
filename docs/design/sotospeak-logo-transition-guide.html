Финальный вариант: Waveform Connected (vC)

✓ Выбран владельцем 2026-08-02
Почему этот вариант Decision

Из 8 сгенерированных вариантов выбран vC (Connected Mic Waveform) по следующим критериям: сохранён ровный стиль оригинального Waveform v2, добавлен микрофон как якорный графический элемент, волна плавно вытекает из микрофона создавая единый поток, нет лишнего слогана.

Вариации логотипа 4 шт

Официальные вариации для разных сценариев использования. Все производятся от мастер-файла.

Primary Full

Полная версия: микрофон → волна → текст. Основной логотип для сайта, презентаций, email.

default

Horizontal

Микрофон и текст раздельно, волна под baseline. Для узких header-ов и мобильных экранов.

compact

Icon / Mascot

Только микрофон с волной — без текста. Для favicon, app icon (512×512, 192×192), аватарок.

icon-only

Monochrome

Одноцветная версия для печати, вышивки, гравировки, чёрно-белых документов.

print
Правила использования Rules

✓ Do

  • Использовать на фоне #EEF3FF или #FFFFFF — максимальная узнаваемость
  • Для app icon — Icon Only (микрофон + волна без текста)
  • Для шапки сайта — Primary Full или Horizontal
  • Сохранять пропорции: не растягивать, не сжимать
  • Минимальный clear space — высота буквы «o» со всех сторон
  • На тёмном фоне (#161A2E) — использовать светлую вариацию

✕ Don't

  • Не добавлять тени, glow, градиенты на сам логотип
  • Не менять цвета: только primary/secondary/record/text из DS
  • Не использовать на шумном или фотографическом фоне
  • Не заменять Nunito на системный шрифт
  • Не обрезать микрофон или волну — они единый элемент
  • Не поворачивать или зеркалить логотип

Адаптация админки Admin UI

Админ-панель SoToSpeak использует ту же дизайн-систему, что и FunnyEnglish Speaking Trainer. Логотип в шапке админки — Horizontal version (компактный, без волны под текстом).

✓ Header Logo

  • Horizontal version — микрофон слева, текст справа
  • Высота логотипа в header: 28–32px
  • Отступ от левого края: 16px (space-l)
  • Цвет фона header: #FFFFFF (surface)

✓ App Icon (Admin PWA)

  • Icon Only — микрофон + волна без текста
  • Размер: 192×192 и 512×512 для manifest
  • Фон: #EEF3FF (periwinkle) или прозрачный
  • Maskable icon: отступ 10% от краёв
