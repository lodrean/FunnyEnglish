1. **Источник перевода**: переводческого API в продукте нет. Варианты: внешний сервис (какой? ключи? лимиты?),
   предзаполненный словарь в БД (кто наполняет, покрытие слов), backend-прокси. Поведение для слова без перевода?
2. **Хранилище личного словаря**: backend (новые эндпоинты, только авторизованные) vs локально

3. **UI-размещение**: где живёт экран личного словаря, если навигация от legacy-фич выпилена по пивоту?
   Нужен ли он в этой итерации вообще (или только «сохранить» без просмотра)?

5. Обновление PRD (строка про словарь в таблице решений 2026-07-30) и/или новая спека-раздел —
