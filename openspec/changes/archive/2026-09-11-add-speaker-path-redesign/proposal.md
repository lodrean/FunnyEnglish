# Proposal: add-speaker-path-redesign

## Why

Дизайн-пакет V1 «Путь спикера» (направление A, деливераблы auto-designer 2026-09-08, копия —
`docs/design/redesign-speaker-path-v1/`) закрывает 5 из 6 точек роста UX-ревью:

1. **Разрыв петли обратной связи** — оценка учителя незаметна: о ней узнаёшь, только если сам
   откроешь «Отправки»; экран Settings существует в коде, но недостижим ни по одному пути.
2. **Навигация «назад» только системная** — `SpeakingAppBar` намеренно без стрелки (по мокапам
   v2.0); на desktop/WASM возврат неочевиден.
3. **Однородная библиотека** — все темы выглядят одинаково, нет чувства «пути» и прогресса.
4. **Мотивационный слой не раскрыт** — профиль: три числа без динамики (кольца/уровни/стрик).
5. **Мелкие противоречия** — CTA к вопросам без мягкой подсказки, нет прогресса попыток в списке.

Режим V1 (зафиксирован в пакете): **перестройка макетов при полном сохранении дизайн-токенов
v1.3.1, флоу и правил попыток** (Training 3 × 80/50/30 с; Practice 30 с, автоотправка, guest-гейты).
Онбординг/авторизация — вне скоупа V1 (кандидат в V2).

Согласование: план внедрения утверждён владельцем 2026-09-08 (сессия ZCode); токен-политика —
строгий маппинг значений прототипа на существующие токены, `tokens.json` не меняется
(DESIGN_SYSTEM_SPEC v3.2.0). bd: эпик `FunnyEnglish-d1e`.

## What Changes

- **Back-кнопка в `SpeakingAppBar`** (отмена «БЕЗ navigationIcon» из мокапов v2.0):
  опциональная круглая кнопка 40dp (surface-фон, рамка outlineVariant, иконка ChevronLeft);
  включается на Topics/Video/Questions/Training/Practice/Settings; системный
  `PlatformBackHandler` сохраняется без изменений (в Practice — диалог-подтверждение §6.1).
- **Бейдж «Отправки»** (нижняя навигация + rail): счётчик оценённых practice-сабмишнов,
  появившихся после локальной метки `lastSeenReviewedAt` (multiplatform-settings, ключ
  `submissions_last_seen`); открытие вкладки «Отправки» обновляет метку и гасит бейдж.
  Оранжевый круг (warning `#FB8C00`, белый текст 11sp/800 только на бейдже ≥2 — одиночная
  цифра «1» по макету), обводка цветом фона навбара.
- **Вход в Settings из Profile**: строка-ссылка (иконка в цветном квадратике 34dp
  secondaryContainer, «Настройки», подзаголовок «Уведомления, звук, вибрация»).
- **Library как «путь»**: карточка «Продолжить путь» (primaryStrong, прогресс последнего
  активного топика в кольце, тап → сразу Questions этого топика) + вертикальный trail
  (линия-ось, узлы: пройдено — success, есть новая тема — record, остальные — трек) +
  карточки тем (обложка 54dp = ThemeCover, линейный прогресс, мини-кольцо процента).
- **Topics**: строки-карточки (thumb 48dp с иконкой play, название, метаданные «видео m:ss ·
  N вопросов», статус-чип).
- **Questions**: hero-карточка активного вопроса (eyebrow «ВОПРОС N ИЗ M», текст QuestionText)
  + компактный список остальных + два CTA «Training · 3 попытки» / «Practice · 30 секунд» +
  примечание «Training остаётся на устройстве · Practice отправится учителю».
- **Video**: CC-бейдж на плеере, прогресс-полоса и таймер моно-шрифтом, транскрипт с активной
  репликой (существующая пословная подсветка), CTA-блок с примечанием «Вопросы всегда
  доступны, даже если видео ещё не просмотрено».
- **Training/Practice**: выверка деталей по макету — чип попытки с иконкой часов, точки
  прогресса попыток, панели result/final («Следующая попытка · 50 секунд», финальный мост к
  Practice), тексты подписей. Поведение и правила попыток НЕ меняются.
- **Profile**: кольцо активности недели (дни с записями), стрик, путь уровней A1→B2 (из XP),
  мини-статы; блоки без данных скрываются (без новых backend-эндпоинтов).
- **Settings**: редизайн строк (иконка в квадратике, заголовок + подзаголовок, свитч/chevron),
  back-кнопка, добавление testTags (сейчас их 0).
- **Не меняется**: маршруты `AppScreen`, MVI-контракты, правила попыток, guest-гейты,
  токены (`tokens.json` v1.3.1), онбординг/авторизация, Messages.
