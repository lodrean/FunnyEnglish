# So to Speak — Инструкция по работе с приложением

> Версия 2.0 · 2026-08-01
> So to Speak — **speaking-тренажёр**: смотрите короткие видео с субтитрами
> и отвечайте на вопросы голосом.
> Документ для двух аудиторий: **ученик** (мобильное/десктоп/web-приложение)
> и **учитель** (админ-панель).

---

## Часть 1. Ученик

### 1.1. Первый запуск и онбординг

При первом запуске приложение показывает короткий онбординг и предлагает выбрать
режим:

- **«Зарегистрироваться»** — полный режим: тренировки + практика с проверкой учителем.
- **«Продолжить как гость»** — без регистрации: доступны тренировки, практика залочена.
- «У меня уже есть аккаунт» — вход для существующих пользователей.

Онбординг показывается один раз. Выбор запоминается на устройстве.

### 1.2. Гостевой режим (без регистрации)

Можно тренироваться сразу, без email и пароля:

- ✅ Смотреть все библиотеки и топики, видео с субтитрами.
- ✅ Режим **Тренировка** — отвечать на вопросы голосом, до 3 попыток на вопрос.
  Записи хранятся **локально на устройстве**.
- ⛔ Режим **Практика** (отправка записи учителю на проверку) — только после
  регистрации. При попытке открыть практику приложение предложит войти.
- ⛔ «Мои записи» и статусы проверки — только после регистрации.

### 1.3. Основной флоу

Навигация построена вокруг **Библиотеки** — это стартовый экран приложения.
Внизу экрана — три вкладки: **Библиотека**, **Мои записи**, **Профиль**.

1. **Библиотека** — выберите библиотеку (например, «Разговорный английский»).
2. **Топики** — список тем внутри библиотеки. У каждой темы видно длительность
   видео, количество вопросов и наличие субтитров.
3. **Видео** — перед просмотром появляется шит выбора:
   - **с субтитрами** (WebVTT поверх видео),
   - **без субтитров**,
   - **пропустить видео** — сразу к вопросам.
4. **Вопросы** — список вопросов по видео и выбор режима:
   - **Тренировка** — до 3 попыток на вопрос, записи остаются на устройстве;
   - **Практика** — одна запись, отправляется учителю на проверку (нужен аккаунт).

### 1.4. Тренировка

- Отвечаете на вопрос голосом, глядя на таймер — **кольцо** вокруг кнопки записи
  показывает оставшееся время.
- Длительность записи зависит от **уровня** (1–3): чем выше уровень, тем длиннее
  ожидаемый ответ.
- На каждый вопрос — **до 3 попыток**: можно прослушать свою запись и перезаписать.
- Записи тренировки не отправляются на сервер — они только у вас на устройстве.

### 1.5. Практика (только с аккаунтом)

- Одна **сплошная запись-голосовое сообщение** с ответами на вопросы топика.
- После записи — прослушивание и кнопка **«Отправить учителю»**.
- Лимиты: запись до 5 МБ (~до 60 секунд).
- Отправленная запись получает статус **«На проверке»**.

### 1.6. Мои записи

Вкладка **«Мои записи»** — все отправленные practice-записи со статусами:

| Статус | Что значит |
|---|---|
| **На проверке** (NEW) | Запись отправлена, учитель ещё не проверил |
| **Проверено** (REVIEWED) | Учитель выставил оценку — откройте запись, чтобы увидеть её |

Оценка состоит из 4 критериев (1–10 каждый): **грамматика, словарный запас,
произношение, беглость** — плюс средний балл и текстовый комментарий учителя.

### 1.7. Переход из гостя в аккаунт

Зарегистрируйтесь или войдите из профиля — откроется режим Практики и вкладка
«Мои записи». Прогресс гостевых тренировок остаётся на устройстве.

## Часть 2. Учитель (админ-панель)

Админка: `http://localhost:3000` (в проде — ваш домен). Вход: учётная запись
администратора (email + пароль).

### 2.1. Контент (CRUD)

Структура контента: **Библиотека → Топики → Видео + Вопросы**.

**Libraries** — библиотеки: название, описание, обложка, порядок, публикация
(Draft/Published). Ученики видят только опубликованные.

**Topics** — топики внутри библиотеки:
1. Создайте топик: название, описание, порядок, статус публикации.
2. **Видео**: загрузите файл видео (до 200 МБ) и, при необходимости, файл
   субтитров WebVTT — укажите длительность.
3. **Вопросы**: добавьте вопросы по видео, порядок задаётся `displayOrder`.

Удаление топика — мягкое (soft delete): топик скрывается, но данные сохраняются.

> ⚠️ Опубликованный топик без видео показывается ученикам без длительности —
> загружайте видео до публикации.

### 2.2. Grading inbox (проверка записей)

Раздел проверки practice-записей учеников:

1. **Фильтры**: статус (на проверке / проверено), ученик, топик, диапазон дат.
   По умолчанию — новые записи, сортировка от свежих к старым.
2. **Прослушивание**: откройте запись — встроенный плеер воспроизводит аудио
   ученика; рядом видны тема, ученик и длительность.
3. **Оценка**: выставьте баллы 1–10 по четырём критериям — грамматика,
   словарный запас, произношение, беглость (средний балл считается автоматически)
   и напишите **комментарий** ученику.
4. **Сохранить** — запись переходит в статус «Проверено», ученик видит оценку
   во вкладке «Мои записи».

Оценку можно **исправить**: откройте проверенную запись и обновите баллы/комментарий.

## Часть 3. Частые вопросы (FAQ)

**Можно ли тренироваться без регистрации?**
Да — гостю доступны все видео и режим Тренировки. Практика (проверка учителем)
требует аккаунта.

**Куда сохраняются записи тренировки?**
Локально на устройстве. На сервер отправляются только practice-записи,
которые вы явно отправили учителю.

**Удалил приложение в гостевом режиме — записи пропали?**
Да: тренировочные записи хранятся локально. Отправленные practice-записи
хранятся на сервере и привязаны к аккаунту.

**Как учитель узнает о новой записи?**
Откройте Grading inbox с фильтром «На проверке» — там все непроверенные записи.

**Видео не загружается в админке / 413 ошибка?**
Проверьте лимит загрузки: nginx должен пропускать до 200 МБ
(`client_max_body_size 200m`, см. `docker/nginx.conf`).
